# Коммерческий выпуск PU Workspace

Перед передачей заказчику выполнить `python scripts/check_release_package.py`, полный `pytest`, frontend `check` и `build`.

Обязательный порядок: создать отдельный release-каталог, передать только `.env.example`, задать уникальные секреты на инфраструктуре заказчика, применить миграции, выполнить `deploy-production.sh`, проверить public smoke и авторизованный pilot preflight.

Production `.env`, OAuth-токены, ключи AI, Telegram и SSH не входят в поставку и не должны попадать в Git или архив продукта. Backup хранится вне release-каталога. Восстановление сначала проверяется в изолированной БД.

Приёмка считается успешной, если readiness зелёный, smoke проходит, мастер запуска открывает точное следующее действие, AI Secretary не создаёт внешних действий без подтверждения, а повторная синхронизация и создание контрольной цепочки идемпотентны.
