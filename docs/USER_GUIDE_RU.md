# PU Workspace — начало работы

## 1. Создайте или выберите проект

Выберите проект в верхнем переключателе. Если создаёте новый проект, сначала сохраните его, затем подключайте источники именно внутри него.

## 2. Подключите рабочую папку

Откройте «Интеграции» → Google Drive → «Выбрать папку». Можно выбрать вложенную папку конкретного объекта внутри общей папки заказчика.

После подключения нажмите «Создать безопасную копию, проанализировать и стандартизировать». Система:

1. строит виртуальный снимок выбранной папки;
2. создаёт отдельную безопасную копию;
3. извлекает текст и классифицирует документы;
4. распознаёт договоры, ГПР, ДДС, акты и другие проектные документы;
5. предлагает единые имена и структуру;
6. автоматически применяет только предложения с высокой уверенностью.

Оригиналы Google Drive не переименовываются и не перемещаются. Низкая уверенность и особые случаи остаются в разделе «Предложения» для проверки.

## 3. Свяжите договор

Откройте «Договоры». Создайте карточку договора и выберите документ-источник из документов проекта. Договор становится юридическим якорем проекта.

После договора используйте цепочку «Договор → ГПР → бюджет → ДДС → акты» в разделе «Исполнение и финансы»:

- выберите нужный договор;
- добавьте или проверьте ГПР;
- добавьте бюджетные строки;
- добавьте план и факт ДДС;
- регистрируйте закупки, поставки и закрывающие акты.

Все записи в этой цепочке должны относиться к одному выбранному договору.

## 4. Разберите входящие письма

Откройте «Интеграции» → Gmail → «Получить письма», затем «Письма» или «AI Secretary».

Если проект не определён автоматически:

1. отметьте несколько писем;
2. выберите проект и при необходимости договор;
3. нажмите «Перенести выбранные».

Связанные задачи, риски и черновики ответов перемещаются вместе с письмом. Оригиналы в Gmail не меняются.

## 5. Ежедневная работа

- «Рабочий центр» показывает требующие внимания пункты.
- «Документы» содержит распознанные документы проекта.
- «Предложения» показывает безопасные изменения до применения.
- «Задачи» и Google Tasks используются только после подтверждения.
- «Обязательства» и «Риски и решения» проверяются по исходным документам.
- «Уведомления» показывает сроки и критические события.
- «Журнал» фиксирует изменения и подтверждения.

## Важно

PU Workspace не должен изменять оригиналы без явного подтверждения. Для массовой обработки сначала проверяйте выбранный проект, договор и папку безопасной копии.
