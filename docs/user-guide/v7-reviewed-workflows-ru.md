# Проверяемые операции: папка, ответ, протокол, график

Инструкция к кандидату `codex/v7-execution-wave6`, 08.09.2026.
Это описание интерфейса кандидата, а не подтверждение установки в production.
Реальные почтовые ящики и документы при разработке не использовались.

## Папка проекта

1. Сначала выберите нужный проект. Не переключайте его во время подтверждения папки.
2. В подключённом хранилище откройте нужную вложенную папку и подтвердите именно её.
3. Запустите обновление состава папки. Оно создаёт задание существующей очереди;
   постановка в очередь не означает завершение анализа.
4. Дождитесь готового снимка. Измеренный прогресс может обновляться крупными шагами;
   отсутствие процентов не означает, что файлы уже обработаны.

Снимок состава — это метаданные дерева, не доказательство чтения каждого документа,
OCR, переименования или создания безопасной копии. Эти действия имеют отдельные
статусы и разрешения. Оригиналы при обновлении снимка не переименовываются.
Если привязка изменилась, старый результат не должен подменить результат новой папки.

## Проверка и отправка ответа

1. Откройте раздел «Письма», затем нужное входящее сообщение.
2. Нажмите «Загрузить черновик для проверки». Проверьте тему, получателя и весь текст.
3. Внесите изменения и нажмите «Сохранить правки черновика».
4. Ещё раз прочитайте сохранённый текст. Нажмите «Подтвердить черновик» отдельно.
5. Статус «Подтверждён — не отправлен» не означает отправку. Она запускается отдельной
   кнопкой «Отправить через Gmail» и отдельным подтверждением.
6. Сообщение «Ответ поставлен в очередь» означает только принятие задания. До
   подтверждения результата системой не считайте письмо отправленным.

Правка и отклонение требуют роли редактора; подтверждение — менеджера согласно
серверной политике проекта. Токен версии не заменяет проверку прав. Отправленный
ответ нельзя редактировать как черновик; корректирующий ответ — отдельный процесс.

Если получен конфликт версии либо результат запроса неизвестен, автоматического
повтора нет. Локальный текст остаётся в форме. Перечитайте серверный черновик;
замена несохранённых правок требует подтверждения. Не повторяйте отправку, пока
не проверен текущий статус. Старые клиенты без версии получат отказ, а не обход проверки.

## Источник протокола встречи

Выберите источник и конкретное доказательство в карточке встречи, сохраните
привязку и проверьте её. Сохранение текста протокола и подтверждение предложения
о задаче — разные операции. Нельзя считать задачу созданной только потому,
что сохранён текст. Отменённая встреча не редактируется этим действием.
При конфликте версии перечитайте встречу; система не должна повторять запись молча.

## График работ

Откройте график нужного договора/базовой версии. Редактируется только черновик.
Изменение длительности или зависимости требует сохранения; расчётные даты
берутся с сервера. Затем отдельным действием утверждается именно сохранённая версия.
Утверждённую версию нельзя незаметно переписать; для изменений нужен новый черновик.

В блоке «Добавление, название и удаление этапов» можно изменить состав черновика.
Добавленный этап получает временную ссылку `new1`, `new2` и т. д. Её можно указать
в зависимости, например `new1FS`. Сохранение состава применяется целиком и отдельно
от утверждения. Удаление связанных с финансами, источниками или фактом этапов
сервер отклонит — финансовые связи не исчезнут автоматически. При конфликте
локальные строки остаются; перечитайте версию и явно решите, какие правки сохранить.

Критический путь и резервы относятся к последнему сохранённому серверному расчёту,
а не к ещё не сохранённым правкам. Производственный календарь и WBS не включены.

## ДДС: один период, четыре вида

В «Исполнение и финансы» найдите «ДДС — один период и область». Выберите договор
или все договоры, задайте даты «ДДС с» и «ДДС по», нажмите «Загрузить период ДДС».
Доступны детали, месяцы, календарь и сводка одного снимка. Переключение вида не
отправляет платежей и не меняет факты. После изменения периода загрузите его явно.

План и факт показаны отдельно по соответствующим датам. Неподтверждённый план,
отменённые/предложенные записи и некорректный факт не становятся подтверждёнными
суммами. Сальдо периода не является банковским остатком. Общие показатели проекта
и прогноз выше не следует путать с этой периодной сводкой.

## Границы проверки

Локальные модульные тесты и браузерные сценарии с синтетическим API не заменяют
PostgreSQL crash/recovery, реальную отправку или провайдерную приёмку.
Кандидат нельзя считать полностью принятым только по зелёной сборке интерфейса.
