# Исправление загрузки папки на компьютере — 03.09.2026

## Причина

Кнопка «Интеграции → Загрузить папку» переводила в рабочий центр и показывала
подсказку вместо выбора файлов. Существующая форма загрузки скрывалась CSS
на экранах шире 760 px.

## Изменения

- Кнопка непосредственно открывает общую форму загрузки на компьютере и телефоне.
- Добавлен выбор папки с сохранением относительных путей вложенных файлов.
- Отправка начинается только после явного подтверждения; используется выбранный project_id.
- При смене проекта выбранные файлы сбрасываются.
- Выбор больше 50 файлов отклоняется с объяснением, без молчаливого обрезания.
- Во время отправки изменение выбора и закрытие формы заблокированы; после ошибки доступен повтор.
- Пересобраны поставляемые backend/app/react_dist файлы. Backend и миграции не изменены.

## Проверки

- Frontend: 27 тестов в 9 файлах прошли; TypeScript и production build прошли.
- Новые тесты: открытие из интеграций, вложенные пути/project_id, отсутствие
  отправки до подтверждения, лимит файлов, отсутствие проекта, ошибка и повтор.
- В локальном браузере на синтетическом стенде проверено открытие и отображение
  диалога при размере 1280×900. Реальная отправка через браузер в этой проверке
  не подтверждена: сессия закрылась до завершения сценария.
- Полная мобильная браузерная регрессия и проверка после deployment остаются обязательными.

## Состояние поставки

На момент подготовки документа рабочий релиз — d619440. Данная правка
не установлена на production. Выпускать отдельным релизом после успешного CI,
с резервной копией БД и сохранением образа для отката. Не заменять существующую
папку релиза и не выводить содержимое .env.
