# Матрица требований Реестра

Матрица предназначена для внутренней проверки. Формулировки и применимость подтверждает профильный юрист по актуальной редакции правил на дату подачи.

| Область проверки | Подтверждённый факт | Что предоставить правообладателю | Статус |
|---|---|---|---|
| Заявитель | Репозиторий не содержит реквизитов заявителя | ОПФ, наименование/ФИО, ОГРН/ОГРНИП, ИНН, адрес, сведения о подписанте и доверенности | блокер |
| Исключительное право | В Git есть история разработки, но она сама по себе не доказывает всю цепочку прав | Трудовые/авторские договоры, служебные задания, акты, договоры подрядчиков, отчуждение прав при необходимости | блокер |
| Территория и срок права | Не подтверждены | Документы о праве на территории всего мира и на весь срок исключительного права; проверить юристом | блокер |
| Контроль/иностранное участие | Не подтверждены | Структура владения и сведения, требуемые действующими правилами | требуется документ |
| Иностранные выплаты | В продукте есть иностранные OSS-компоненты и внешние API | Расчёт платежей иностранным лицам, договоры SaaS/cloud/API, методика расчёта применимых порогов | блокер |
| Наименование и версия | Рабочее наименование PU Workspace; версия релиза не выбрана | Утвердить официальное наименование, редакцию, release SHA и обозначение версии | требуется решение |
| Функциональность | Подтверждается кодом и документацией | Утвердить публичный текст и проверить его на соответствие эталонному релизу | готово |
| Документация | Подготовлены проекты публичных материалов | Разместить на постоянном URL правообладателя и обеспечить доступность | блокер |
| Стоимость | В репозитории цена отсутствует | Утвердить модель, цену/порядок расчёта, НДС, поддержку и внешние расходы | требуется решение |
| Класс ПО | Возможны 05.05, 09.01, 09.11, 05.13 и 12.08 | Выбрать основной и дополнительные классы после сверки классификатора и фактических функций | требуется решение |
| ОКПД2 | Возможны 58.29.21, 58.29.29, 58.29.32, 62.01.29 | Проверить допустимые коды с юристом/классификатором; не заявлять все автоматически | требуется решение |
| Компоненты | Прямые зависимости видны в manifests | Сформировать SBOM эталонного SHA, добавить транзитивные/системные компоненты, лицензии и правообладателей | требуется документ |
| Установка | Docker-сборка ориентирована на Linux x86_64 и PostgreSQL 16 | Независимый протокол установки, checksum, требования к сети и браузерам | требуется документ |
| Экспертный доступ | Процедура подготовлена | Выдать отдельные учётные данные, тестовый контур/пакет, назначить контакт | требуется решение |
| КЭП/Госуслуги | Не проверяется репозиторием | Подтверждённая учётная запись и квалифицированный сертификат ключа подписи | блокер |
| Персональные данные | Есть RBAC, аудит и шифрование токенов | Юридическая модель обработки, локализация, поручение обработки, политика и ИБ-проверка | требуется документ |

## Предполагаемая классификация — требует проверки

| Кандидат | Основание | Решение |
|---|---|---|
| **05.05 Средства управления проектами** | проекты, задачи, сроки, риски, ГПР | Вероятный основной класс; требует проверки |
| **09.01 Средства управления бизнес-процессами (BPM)** | маршруты документов, согласования, действия и контроль | Возможный основной/дополнительный; требует проверки |
| **09.11 Средства управления содержимым (CMS), сайты и портальные решения** | документное ядро, версии, поиск, связи | Дополнительный; требует проверки |
| **05.13 Средства интеллектуальной обработки информации и интеллектуального анализа бизнес-процессов** | AI Secretary, классификация и извлечение | Дополнительный только при подтверждённом объёме функций; требует проверки |
| **12.08 ПО для отраслевых задач в области строительства зданий и инженерных сооружений** | ГПР, договоры, ДДС и исполнение строительных проектов | Отраслевой класс возможен, но продукт заявлен шире; требует решения |

Предполагаемые ОКПД2: **58.29.21**, **58.29.29**, **58.29.32**, **62.01.29** — каждый код требует отдельной проверки актуального классификатора и модели поставки.
