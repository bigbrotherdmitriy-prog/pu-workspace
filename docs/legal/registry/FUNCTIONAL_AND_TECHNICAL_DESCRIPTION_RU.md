# Функциональное и техническое описание PU Workspace

## Назначение

PU Workspace — веб-система для ведения проектов, документов, договоров, задач, обязательств, рисков, решений, переписки и показателей исполнения в едином проектном контексте. Значимые внешние, юридические и финансовые действия требуют подтверждения пользователя.

## Подтверждённые функции эталонной кодовой базы

- проекты, участники, роли и аудит действий;
- реестр документов, версии, поиск и связь с задачами/рисками/решениями;
- безопасная рабочая копия папки, анализ и предложения стандартизации без изменения оригиналов;
- договорный контур и связи договоров с документами;
- задачи, обязательства, совещания, риски и решения;
- ГПР, бюджет, ДДС, закупки, поставки и акты в режиме управляемых записей;
- входящие сообщения, черновики ответов и AI Secretary;
- внешние интеграции через адаптеры; текущий Vertical Slice использует Google Workspace, Telegram и Gemini;
- PostgreSQL-очередь длительных операций, retries, lease и dead-letter;
- локальное извлечение текста/OCR через Tesseract и Poppler.

## Ограничения заявления

Наличие интерфейса адаптера не означает наличие готовой интеграции с Яндекс 360, VK WorkSpace, Microsoft, банками или любым другим поставщиком. Эти варианты не должны публиковаться как реализованные до отдельной приёмки.

AI не принимает окончательных юридических или финансовых решений. Результаты извлечения и предложения требуют проверки человека, особенно при низкой уверенности.

## Поддерживаемая программная среда

| Компонент | Подтверждённая база | Ограничение |
|---|---|---|
| Серверная ОС | Linux-контейнер `python:3.12-slim`, архитектура x86_64 | Совместимость с конкретной российской ОС требует протокола испытаний |
| Контейнеризация | Docker Engine и Compose | Конкретные версии закрепляются для эталонного релиза |
| СУБД | PostgreSQL 16 | Другие СУБД не заявляются |
| Клиент | Современный браузер с JavaScript, адаптивный web UI | Матрица браузеров требует отдельного теста |
| OCR | Tesseract rus+eng, Poppler, antiword | Качество зависит от скана; низкая уверенность требует человека |
| Хранение | PostgreSQL и подключаемый StorageAdapter | Текущая промышленная реализация адаптера — Google Drive |

Стартовый профиль для пилота: 4 vCPU, 8 ГБ RAM, Linux x86_64, отдельный постоянный диск PostgreSQL и резервное хранилище. Это не гарантированный минимум: итоговые требования определяются нагрузочным тестом, объёмом документов, OCR и числом пользователей.

## Варианты размещения

| Вариант | Описание | Статус |
|---|---|---|
| PU Workspace Cloud | Контур, управляемый поставщиком | Требуется решение владельца, договор и описание площадки |
| Российское облако/ЦОД | Docker Compose/контейнеры и PostgreSQL в выбранной инфраструктуре | Архитектурно возможно; конкретная площадка требует теста и договора |
| Private cloud | Изолированный контур заказчика с его secrets, доменом и backup | Архитектурно возможно; требуется проект внедрения |
| On-premise | Установка на Linux-инфраструктуре заказчика | Поддерживается инструкцией; совместимость конкретной ОС/железа проверяется отдельно |
