# V3-04b — каталог ресурсов и помещений

Статус: **BACKLOG / NOT IMPLEMENTED**  
Решение владельца: вынесено из V3-04a в отдельный будущий цикл.

## Граница V3-04a

V3-04a обнаруживает пересечения встреч только по структурированным участникам
(`user_id` / `contact_id`) и полуоткрытым временным интервалам. Создание встречи
не блокируется: API и интерфейс возвращают предупреждение.

## Отдельное решение для V3-04b

До реализации требуется отдельный preflight и подтверждение владельца для:

- каталога помещений, техники и других бронируемых ресурсов;
- tenant-scoped идентичности ресурса и правил доступа;
- часового пояса, вместимости и доступности;
- повторяющихся бронирований и исключений;
- политики предупреждения или блокировки для разных типов ресурсов;
- импорта/сверки с внешними календарями помещений.

V3-04a не создаёт временных строковых идентификаторов ресурсов и не пытается
угадывать ресурс по старому свободному тексту `participants`.
