## Технически подтверждено

- manifests/lock-файл присутствуют; версии извлекаются повторяемо;
- container bases: `postgres:16-alpine` и `python:3.12-slim`, без digest pinning;
- vendored шрифты и `@font-face` не найдены; UI использует системные шрифты и `lucide-react`;
- tracked production `.env`/private keys/API tokens шаблонным поиском не найдены; `.env.example` содержит placeholders;
- Git identities обнаружены, но не признавались юридическими авторами;
- тесты содержат идентификаторы, похожие на клиентские; `backend/tests/**` исключены из коммерческого архива;
- production deploy, server access, Android, backups, sales, пользовательские данные и secrets исключены allowlist;
- сборщик читает только Git commit и нормализует порядок, uid/gid, mode и время архива.

## Готовность

| Категория | Статус | Продажа | Пилот |
|---|---|---|---|
| Формы 01–09 и единый реестр | готово к заполнению | после заполнения | не блокирует |
| Цепочка исключительных прав | требует владельца/юриста | **блокирует** | только по решению юриста |
| Модель сделки и реквизиты | требует сторон/юриста | **блокирует** | не блокирует внутренний пилот |
| SPDX declarations | готово технически | недостаточно без license resolution | не блокирует внутренний пилот |
| Полные OSS notices/container digests | не закрыто | **блокирует** | не блокирует закрытый пилот |
| CI/restore/independent-install logs | формы готовы, прогон впереди | **блокирует проверенную передачу** | с явным статусом |
| ПДн/AI роли, сроки, субобработчики | требует заказчика/юриста | **блокирует реальные данные** | демо на синтетике |

## Команды

- `python scripts/legal_release_kit.py sbom --ref <SHA> --out <DIR>` — три SPDX 2.3.
- `python scripts/legal_release_kit.py all --ref <SHA> --out <EMPTY_DIR>` — SBOM, archive, manifest, checksums и audit; secret/client scan работает fail-closed.
- `git archive` не использовать как коммерческий пакет: он не применяет allowlist.

## Вывод

Каркас комплекта готов к заполнению и внешней проверке. До продажи остаются реальные блокеры: доказательства цепочки прав; согласованная модель сделки; закрытие лицензий третьих лиц; release-specific test/restore/install logs; режим ПДн и AI. Эти сведения нельзя достоверно получить только из исходного кода.
