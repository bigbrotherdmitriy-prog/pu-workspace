# Яндекс Диск: настройка OAuth

Интеграция добавлена рядом с Google Drive. Существующие Google-проекты, их
`folder_id`, токены и индексы не мигрируются и не изменяются.

## 1. Создание приложения

1. Откройте [Яндекс OAuth](https://oauth.yandex.ru/).
2. Создайте приложение типа «Веб-сервисы».
3. Добавьте права Яндекс Диска на чтение и запись. Для безопасной копии нужны
   оба права; PU Workspace не изменяет оригиналы.
4. Укажите Redirect URI, совпадающий с публичным адресом API, например:
   `https://workspace.example.ru/projects/yandex/callback`.
5. Скопируйте Client ID и Client secret непосредственно в секреты среды
   размещения. Не вставляйте их в чат, git, логи или export bundle.

## 2. Переменные среды

```dotenv
YANDEX_CLIENT_ID=
YANDEX_CLIENT_SECRET=
YANDEX_REDIRECT_URI=https://workspace.example.ru/projects/yandex/callback
```

Также обязателен `TOKEN_ENCRYPTION_KEY`: access/refresh tokens сохраняются
только в зашифрованном виде. При ротации применяется существующий механизм
`TOKEN_ENCRYPTION_PREVIOUS_KEYS`.

## 3. Acceptance-сценарий с реальным аккаунтом

1. Открыть «Интеграции» → «Яндекс Диск» → «Подключить».
2. Разрешить приложению доступ и убедиться, что callback вернул в PU Workspace.
3. Нажать «Выбрать папку», пройти на несколько уровней вложенности и выбрать
   корневую папку проекта.
4. Проверить статус подключения и имя аккаунта.
5. Запустить снимок дважды: второй запуск не должен дублировать документы или
   безопасную копию с тем же idempotency key.
6. Проверить, что исходная папка и имена оригиналов не изменились.
7. Отключить Яндекс и открыть старый Google-проект: Google OAuth и папка должны
   остаться прежними.

Автоматические тесты используют `httpx.MockTransport`; реальные credentials
для CI не требуются.

## Ограничения среза

- Яндекс Почта и Календарь не реализованы.
- Shared Drive, S3/MinIO, VK и Microsoft не реализованы.
- Удалённый отзыв обычного web-токена зависит от типа токена Яндекса; локальные
  зашифрованные credentials удаляются всегда. Пользователь также может отозвать
  доступ на странице прав Яндекс ID.
- Managed workspace template пока создаётся только в Google Drive. Обычный
  Project/Document Core, выбор вложенной папки, снимки и безопасные копии
  работают через общий StorageAdapter.
