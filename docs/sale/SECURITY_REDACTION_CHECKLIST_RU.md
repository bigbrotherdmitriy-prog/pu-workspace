# Проверка поставки перед передачей

- [ ] В архиве отсутствуют `.env`, deploy keys и `server-access`.
- [ ] Отсутствуют токены Telegram, Google OAuth secrets и AI API keys.
- [ ] Отсутствуют дампы production-базы и пользовательские загрузки.
- [ ] Отсутствуют cookies, OAuth refresh tokens и журналы с персональными данными.
- [ ] `.env.example` содержит только имена переменных и безопасные примеры.
- [ ] Git history проверена на ранее закоммиченные секреты.
- [ ] Покупателю передаётся новый чистый архив, а не рабочая папка продавца.
- [ ] Для архива рассчитан SHA-256 и он указан в акте.
- [ ] Покупатель письменно уведомлён, что должен создать собственные credentials.
- [ ] Production продавца не используется для приёмки после передачи.
