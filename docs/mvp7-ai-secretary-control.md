# MVP7 — управляемый AI Secretary

MVP7 превращает AI Secretary в контролёр повторяющихся проектных действий,
но не даёт ему права самостоятельно отправлять письма или фиксировать оплату.

## Приёмка

- [x] ежемесячный регламент связан с проектом, договором и опорным документом;
- [x] день месяца корректно переносится на последний день короткого месяца;
- [x] каждый период идемпотентно создаёт одну контрольную задачу и один черновик;
- [x] доступны шаблоны проекта, договора, текущего и следующего месяца;
- [x] результат последнего запуска виден в карточке регламента;
- [x] из карточки можно открыть задачу и черновик письма;
- [x] правило можно приостановить и запустить вручную;
- [x] внешняя отправка требует утверждения черновика пользователем;
- [x] факт оплаты создаётся только отдельным подтверждением пользователя.

Следующий уровень автоматизации должен добавляться через новые типы правил и
адаптеры. Он не должен обходить Approval, Audit и AI policy проекта.
