# MVP6 — документный контроль исполнения

MVP6 связывает уже проанализированные документы проекта с управленческим
контуром, не изменяя оригиналы и не создавая финансовый факт автоматически.

## Приёмка

- [x] ГПР, бюджет/смета, ДДС, счёт и акт распознаются по имени и полному тексту;
- [x] для предложения показываются уверенность и причины классификации;
- [x] из документа извлекаются подсказки суммы, даты и номера;
- [x] счёт и акт сохраняют ссылку на документ-источник;
- [x] повторно связанные документы помечаются в интерфейсе;
- [x] пользователь проверяет поля до создания предложения;
- [x] исходный документ не переименовывается и не изменяется этим сценарием.

Переименование рабочей копии остаётся отдельным пакетным процессом
`анализ → предложение → подтверждение → применение → откат`.
