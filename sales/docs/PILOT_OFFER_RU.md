# Рамка пилота PU Workspace

Это рабочая основа предложения, а не публичная оферта и не утверждённый прайс.

## Рекомендуемый формат

- один бизнес-процесс;
- один владелец процесса со стороны клиента;
- согласованный набор источников и тестовых данных;
- срок 2–4 недели после готовности доступов;
- еженедельная контрольная встреча;
- финальный отчёт по критериям результата.

## Что фиксируется до старта

- проблема и ожидаемый эффект;
- границы пилота и исключения;
- перечень данных и правила их обработки;
- необходимые интеграции;
- ответственные стороны;
- критерий приёмки;
- стоимость, порядок оплаты и условия продолжения.

## Примеры критериев результата

- система находит согласованный тип обязательств с подтверждаемой ссылкой на источник;
- время первичного разбора входящего сокращается относительно базового замера;
- пользователь видит единый список требующих реакции пунктов;
- предложенные задачи создаются только после подтверждения и сохраняют связь с источником;
- все значимые действия присутствуют в журнале аудита.

Цену нельзя публиковать до утверждения владельцем продукта. Для каждой компании сначала проводится диагностика, затем выдаётся фиксированное предложение на ограниченный пилот.
