# PU Workspace Sales Bot

Отдельный Telegram-бот для потенциальных клиентов и заявок на Early Access.
Он не является `PUSuperbot` и не содержит бизнес-логику основного PU Workspace.

Публичное имя продающего бота: `@puworkspace_bot`.

## Что реализовано

- фирменное стартовое меню;
- утверждённые ответы о продукте без завышенных обещаний;
- разделы «Возможности», «Кому подходит» и «Материалы»;
- пошаговая заявка на Early Access;
- сохранение лидов в SQLite;
- уведомление владельца в Telegram;
- согласие клиента до сбора контактных данных;
- мини-CRM: список, статистика и статусы заявок;
- идемпотентная обработка Telegram updates;
- хранение состояния диалога после перезапуска;
- запуск через long polling без Replit;
- Docker-конфигурация для отдельного сервиса на VPS.
- источники заявок из рекламных ссылок (`/start site_hero`);
- единый контакт для продаж: `hello@puworkspace.ru`;
- опубликованные PDF-материалы прямо из меню бота.

## Безопасный запуск

1. Скопировать `.env.example` в `.env`.
2. Записать токен именно продающего бота в `PU_SALES_BOT_TOKEN`.
3. Записать Telegram chat ID владельца в `PU_SALES_ADMIN_CHAT_ID`.
4. При наличии добавить публичные ссылки на презентацию и буклет.
5. Запустить:

```sh
docker compose up -d --build
docker compose logs -f sales-bot
```

Токен и база лидов не входят в образ и не должны попадать в Git.

## Проверка

```sh
python -m unittest discover -s tests -v
```

В Telegram отправить `/start`, открыть разделы и пройти заявку до конца.

## Команды

- `/start` или `/menu` — главное меню;
- `/id` — показать chat ID владельца для настройки уведомлений;
- `/leads` — последние десять заявок (только владелец);
- `/stats` — статистика воронки (только владелец);
- `/cancel` — отменить заполнение заявки.

## Контентная политика

Бот сообщает, что продукт находится в Early Access. Google Workspace описывается
как текущий референсный набор интеграций, а Яндекс 360, VK WorkSpace, Microsoft и
другие системы — как расширяемый roadmap. Бот не обещает функции, которые не были
подтверждены для конкретного пилота.
