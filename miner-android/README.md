# CPU Miner для Android

Приложение майнит Monero (RandomX) на процессоре телефона через [xmrig](https://github.com/xmrig/xmrig).
Kotlin + Jetpack Compose. Майнинг запускается только кнопкой, работает в foreground-сервисе
с постоянным уведомлением и кнопкой «Стоп».

## Что умеет
- Пул, кошелёк и воркер вводятся в приложении
- Выбор числа потоков
- Автостоп при перегреве, низком заряде или отключении зарядки
- Хешрейт, принятые и отклонённые шары, температура и заряд на экране

## Сборка
1. Скачайте `xmrig` для Android arm64 (или соберите из исходников с NDK).
2. Положите бинарник в `app/src/main/jniLibs/arm64-v8a/` под именем **`libxmrig.so`**.
   Имя `lib*.so` нужно, чтобы Android распаковал файл в `nativeLibraryDir`, откуда его можно запустить.
3. Откройте папку в Android Studio (Ladybug+) или выполните `gradle :app:assembleDebug`
   (в корне нужен gradle wrapper: `gradle wrapper`).
4. Установите APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Честно о доходности
Телефон выдаёт порядка 100–500 H/s на RandomX. Это центы в месяц при расходе заряда и износе батареи.
Приложение даёт технический эксперимент, а не заработок.

## Правила
- xmrig распространяется под GPLv3, так что при раздаче APK нужно выложить исходники.
- Google Play запрещает приложения, которые майнят на устройстве. Раздавайте через сайт или F-Droid.
- Приложение не скрывает майнинг: запуск только по кнопке с согласием пользователя. Не делайте скрытый запуск, это вредоносное ПО (cryptojacking).
